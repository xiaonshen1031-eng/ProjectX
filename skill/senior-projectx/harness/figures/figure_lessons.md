# Figure Lessons

- Define the scientific question before selecting a plot family.
- Do not use a standalone figure when a table already communicates a low-information metric adequately.
- Keep legends inside only when required, and position them using actual data occupancy so they do not cover curves or markers.
- For heatmaps, compute text color from rendered cell luminance; inspect colorbar endpoints after EMF insertion.
- Treat standalone-source QA and Word/PDF-rendered QA as separate gates.
- Preserve normal physical aspect ratios; fix clipping by changing canvas and axes geometry before shrinking text.
- Use vector output when required, but verify the package relationship and actual inserted media type rather than trusting the filename.

## physical panel repair

Tiny labels in a multi-panel layout are a final-width problem. Change the generator's typography and preserve aspect ratio; export each requested EMF separately. A crop must preserve every plot frame edge, legend and label. Place an inside top-centered legend only with safe padding and no data/number occlusion. Validate through Office at the intended physical size. Specific centimeter crops and source font sizes remain local, not recipe defaults. A display sample never replaces the metric population.

## editable mechanisms and decision results

- Choose the figure's scientific job before its layout: a mechanism overview, an operational workflow and a verified decision result require different visual structures. Complexity comes from real dependencies, state changes and admissible alternatives; extra icons, panels and text do not supply it.
- Resolve empty or tangled composition before polishing icons. Use one dominant system, planned connection lanes and a local sequence attached to the actual system objects. Keep scene icons subordinate to the mechanism.
- Treat the user's current editable file as authoritative. Preserve accepted text, icons, line styles and geometry during bounded repairs, including constraints confirmed in earlier turns. Export-only work must not regenerate an older design.
- Inspect ports, junctions, arrows and crossings at local scale and final print size. Distinguish an electrical junction from a nonjoining bridge; remove tails and redundant bends without closing a real open switch or a damage gap. Short dashed connections need visible, closely spaced dashes.
- Show preparation/domain/action decisions with saved statuses and actual successor outcomes. Keep default and cost-sensitive settings explicit, preserve censored thresholds and branch/support distinctions, and do not turn result redesign into new experiments or a generic workflow.
- Keep native text, connectors, symbols and curves editable; scene pictures remain independent transparent objects. A flattened full-figure image inside an editable container does not satisfy native editability.
- Preserve the source when exporting EMF and integrate into a manuscript copy. Clear inherited character-based picture indents, map figure numbers and references once, preserve unrelated native equations/media, and verify the actual final Word rendering.

Operational details: [editable diagram playbook](../../references/editable-diagram-playbook.md), [decision-validation results](../../references/advanced-figure-workflow.md), and [Word figure integration](../../references/word-figure-integration.md).

## scaled connectors and complementary curve evidence

- A broad or clipped arrowhead is not repaired by repeatedly shrinking every arrow. Check source-to-print scaling, terminal straight length, head width, painted bounds and the affected connection's stem. Preserve intentional weight hierarchy and explicit user values; approximately 3 pt was a local request.
- Repeated stages and icon families need shared visible centers, label baselines and routing anchors. Picture-frame coordinates alone miss transparent margins. Inspect whole small motifs; a clipped search-tree branch is a source geometry defect.
- Every legend sample and numbered callout needs a visible, semantically matching target. Remove unused keys or repair their encoding within the authorized scope; do not add an unsupported mechanism.
- Replace low-information panel repetition with a matched effect summary and aligned case diagnostics when saved arrays support them. Observed/reference/coordinated curves, output changes and expert-weight changes explain different parts of one mechanism; added curves require actual evidence.
- Preserve population/fold/task denominators, fixed representative cases, member order, units and uncertainty semantics. Expert min–max/IQR bands show finite-expert dispersion; they do not establish predictive coverage. Peak markers do not create threshold events or prove novelty.
- Keep data coordinates truthful during layout repair: reserve colorbar endpoint space and use style or categorical spacing for overlapping zeros. Never relabel an inward-moved tick as the original boundary or move a zero effect along the value axis.
- Keep native formula editability in the requested source separate from the exported EMF picture. Verified payload reuse remains reuse. Check apparent EMF/Alpha defects in native Office before changing accepted sources; bound automation retries to a changed cause.

## 原生Office对象与副本
PPT源稿可能已打开，检查入口必须先复制再打开副本。图表数值同时检查缓存与工作簿。编辑持久性确认后整体恢复测试副本，避免只恢复单元格留下旧缓存。公式编辑器打开或键入可见文字均不能证明写回，应对保存重开的MTEF内容和实际页面进行核对。
