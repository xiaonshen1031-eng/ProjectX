# 连贯分析的写法

正文沿技术数量展开：输入确定研究对象，物理或数学关系形成输出，输出继续回答工程问题。新符号随关系定义，解释相邻公式组，不逐式重复符号表。

“响应时长增加后，可调功率下降。能量约束限制了同一设备持续削减的电量，因此较长响应需要分配更多设备。” 仅在实际模型和结果支持这两个关系时采用这类分析。

“在低负荷时段，基准方案的误差更小。” 直接保留相反结果，按实际残差或约束解释，不接自我辩护。

表格保留准确数值，正文选取能够回答问题的少数数值，并说明变量、约束与结果的关系。图的多个面板可以共同支持一个结论，也可以分别解释不同数量；不要把图题扩写成分析段落。

适配数据在资料与模型部分说明来源曲线、目标规模、权重、时间尺度和守恒关系。必要条件集中放在对应位置，图下只保留辨识图件需要的名称与单位。
