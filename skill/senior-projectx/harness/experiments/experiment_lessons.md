# 数据与计算经验

- 原始数据、公开曲线、适配结果和模型响应分别记录，区域适配须明确规模、单位、时间与分配分母，并检验守恒。
- 零值、缺失和不可行不能混用；选择性隐藏零值只作用于用户指定的显示，不改变计算样本和分母。
- 参数、预处理和模型选择使用允许的训练或验证区间，时间预测不让未来信息进入历史决策。
- 比较使用相同对象、指标、时间和可用信息。最优性来自实际目标与约束；完整保留不利结果。
- 从输出重新代回方程和约束进行独立复算。固定依赖顺序回放只评价该顺序。
- 结果分析核对均值、峰值、分位数、单位、区间与比例分母，区域同时峰值由同步序列求和后计算。
- 场景范围、成员离散与统计置信区间含义分别定义；显著性比较不等于预测区间校准。
- 上游改变只重算实际依赖的结果、图和正文，不创建无人使用的记录。

## 功率与电量的连续分析
在电力分配问题中，可分配功率为设备容量扣除基础负荷；调度后余量再扣除实际分配功率。按时间窗积分得到可供电量，与需求电量比较。结果分析由输入变化进入约束分布和工程影响，保留关键数量，不逐格复述表格。
