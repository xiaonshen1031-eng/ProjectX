# 已批准文字和原生内容的局部修订

以用户指定的保存稿为基准。若同时给出 PDF，用相同公式、图表、关键段落或绑定文件哈希的导出记录确认对应。分别记录修订项、目标段落、需要保留的对象及实际变更。重复句用前后文和研究对象消歧，定稿后重新定位受插删影响的段落。

逐项应用已批准的措辞。一个段落中的普通文字、可编辑公式、引文字段、交叉引用、书签和对象预览使用不同的 Word 结构。用 `.text = ...` 重写混合段落会覆盖这些结构。按普通文本实际位置修改文本节点，保留原生对象、REF/SEQ 字段和引用范围。需要随修订移动时，在结果页核对对象顺序和归属。若指定文字与必须保留的公式含义确有冲突，先完成可确定的修订，再把具体冲突定位到相应段落。

核对原生公式的关系和载荷，单独比较编号、表内数据、图的聚合范围和单位。仅凭对象总数无法定位替换、重复或丢失。压缩文字后用冻结的结果检查科学含义，尤其是电量守恒范围、对照信息、统计单位和适用约束。需要检查改写字数时，按用户要求选择同一文本范围和计数规则用于两稿。

```powershell
python scripts/audit_word_revision.py baseline.docx revised.docx --json-out review/protected.json
python scripts/audit_word_revision.py clean.docx marked.docx --highlight-color yellow --json-out review/pair.json
```

第一条逐部分比较原生公式、关系、媒体、字段、书签和表格内容，保护顺序及内容。`--allow-change` 可重复传入用户已授权改变的比较类别，报告仍显示该类别的差异。脚本用于可定位的结构差异，例如检查修段后原生公式和图件是否受损。原生表达式经 Word 另存时发生等价重编码、或经授权重新排序时，须结合对象内容与预览检查。

用户要求高亮时，从同一最终稿派生干净稿和标记稿。仅对实际替换或新增的普通文字做所需颜色的高亮。纯移动、删除和公式更换按用户要求记录。第二条只归并同格式的相邻普通文本和指定高亮，检查剩余各部分是否一致，并报告被标记的文字数量。用逐项定位检查变更范围，再检查两稿的实际页面和实际文本。结构比较不代替修订项覆盖、固定文字核对及 Word 重开和视觉检查。

最终文件按 [Word 定稿](word-pagination-and-citation-release.md) 验证。任务只涉及排版或已给定的文字修订时，沿用既有研究证据。
