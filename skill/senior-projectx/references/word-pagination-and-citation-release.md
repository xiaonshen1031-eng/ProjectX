# Word 分页、公式和引文定稿

局部排版先确定用户认可的保存稿。用当前模板确定版芯、栏宽、正文与题注、表格行距、公式编号区和首页、奇偶页的页眉页脚。核对 Word 实际页面。章节结尾处的节属性作用于此前一节。正文出现“表2列出”时仍为正文，图表角色以其实际结构和样式为准。

## 诊断分页

- 页尾空白可能来自手动分页、空段、段落网格、不可拆分表格、图题与图的串联分页属性，或图片本身留白。先查具体原因，再决定移动整组图题、表下注或相关段落。
- 题注随图表同页，标题随其首段。表格超出一页时按模板决定跨页规则，保留可识别的表头、行和单位。可在同一技术小节内调整阅读顺序，确保正文先介绍图表并用正确编号指向它。
- 只在有实际断行问题的数值和单位之间使用不换行空格。修后检查是否产生新的短尾行。时间范围、公式、连续英文和标点各按实际排版处理。
- 保留模板要求的网格和页眉页脚字段。若行内公式被网格抬高导致跳行，先确认模板是否允许局部自然行高。版芯不足时先检查段落缩进、制表位和编号区。表格宽度按数据确定，图片调整保持原比例。
- 以可读性和章节连贯为准，页数由内容自然决定。大图或可读表格整组换页后的合理空白，按实际页面判断。

## 保存原生公式和图表

公式本体保持可编辑，保留内联、行间和表内位置及目标表达式。整条公式放不下时，区分需要重排的一条表达式和合理并列的多行约束。检查实际原生对象尺寸、当前版芯居中和右侧编号。调整公式内部行列意味着修改公式，需要核对目标表达式、原生内容和可见结果。

周边排版可用 [局部修订核对](fixed-revision-integrity.md) 比较原生公式、关系、预览、图表数据和字段。已转换的 MathType 文件直接修排版。现有公式证据仅在逐对象载荷和预览保持一致时复用，并绑定到实际重开的交付文件。不同 Word 保存器可能重写等价的 XML，此时核对差异的实际含义、对象和渲染。

## 数字引文检查

采用客户模板或用户指定的引文形式。GB/T 7714 顺序编码为默认格式，是否使用 Word REF、是否上标、是否保留文献由交付要求决定。收到删除参考文献和引文编号的要求时，只移除关联文献组及其相关标记。公式、章图表序号、统计区间与来源说明按各自用途处理。

```powershell
python scripts/audit_word_citations.py report.docx --bib-heading "参考文献" --require-all-cited --json-out review/citations.json
python scripts/audit_word_citations.py report_without_bibliography.docx --without-bibliography --json-out review/no_bibliography.json
```

第一条用于带方括号数字和 REF 的文档，其报告区分一组引文、几个 REF 字段和覆盖几条文献。用 `--resume-heading` 指明文献后的正文或附录标题。模板要求完全上标时加 `--require-superscript`，核对包括括号、横线及 CHARFORMAT 指令格式。Word 自动编号和 `REF \n` 等开关需要 Word 求值。第二条只用于明确要求无文献引注的版本。普通方括号中的数字仍可能是数学范围或算法标识，需回到语境辨认。

两条命令检查主文档、表题和单元格、已有脚注和尾注中的缓存结构。需要核实文献元数据、其他类型引文或页眉页脚时按对应格式检查。报告的 `word_update_verified` 始终为 `false`。

## Word 保存重开

```powershell
powershell -File scripts/project_word_roundtrip.ps1 -SourceDocx report.docx -OutputDocx review/reopened.docx -OutputPdf review/render.pdf -InspectionJson review/word.json
```

脚本先复制文件，只打开本次副本。默认先更新 `SEQ`，再更新 `REF`，重新打开后比较实际字段值和上标。`-RefreshFields` 可选择需要更新的字段类型，还支持 `PAGEREF`、`PAGE` 和 `NUMPAGES`。只做复开、导出时用 `-NoFieldRefresh`。目录等其他字段在有具体需求时单独操作。更新编号时避免激活 MathType 编辑器或在整个文档运行无差别字段刷新。

选一个本次启动的 Word 实例，绑定进程 ID、启动时间和实际打开的副本路径。工作涉及已有 Word 实例时先确认实例权限和文档身份；脚本按自己创建的会话收尾，保留用户的其他文件。刷新结果、交付 DOCX、PDF 用哈希关联，检查文件只证明实际执行过的操作。`render_review_pending` 表示仍需逐页看图。整稿交付检查全稿，局部改动检查实际页面及受分页影响的邻页。核对公式、图表及说明、文字断行、页眉页脚和书目末页。仅当文件或渲染页可证实相同，才能复用对应范围的既有检查。
