# 六类工程结果图的选图与复算

先找出需要判断的运行条件。超限总时长和超限发生时刻是两个问题，前者可用持续曲线，后者可用日历。若日历显示调节把负荷挪到了控制结束后，接着用匹配工况的反弹图检查回补电量，以及回补是否与新的紧约束时段重合。结果小节可以沿这条关系推进，表保留精确值，图展示关系，正文给出受到哪些条件约束的判断。

| 选择 | 适合回答 | 图里应当同时能看到 | 继续核查 |
| --- | --- | --- | --- |
| `duration` 负荷持续曲线 | 调度前后分别超限多久、超出多少电量？ | 同一组时段的两条按时长加权的排序阶梯线、容量线、累计超限电量。 | 排序打散了日历次序。需要判断是否连续超限或在哪些时刻超限时，回看原时序或约束日历。 |
| `saturation` 约束饱和日历 | 余量在哪些小时收紧，是否反复集中在同一时段？ | 逐日逐时的超限、低余量、余量充足和缺测四类，右侧逐日合计分别对应同一行。 | 低余量阈值取自工程条件。把反复出现的时段对齐资源接入、基荷和上游限值，核对哪个约束收紧。 |
| `energy-bridge` 调节能量收支 | 电网购电量改变多少，其中哪些是转移、储能补充或设备节电？ | 每项有符号变化、累计值，以及两端独立计量的购电量。 | 从绘图底稿核对闭合差。若移峰调入调出成对，先核对其净值，再判断是否存在节电。 |
| `rebound` 负荷反弹 | 一次调节削减的电量有多少在恢复窗内被补回？ | 按控制时点对齐的同窗功率差、控制与恢复窗口、逐对积分及等量回补线。 | 先校核配对条件和时窗。对角线判读用于削减为正的样本。超限风险还取决于回补发生时的实际负荷与上限。 |
| `hysteresis` 温控滞回 | 同一室温附近为何会出现两种负荷，运行状态在哪里切换？ | 室温—功率路径、设置的开停阈值、观测到的切换点及同轴时间轨迹。 | 核对控制器时延、采样粒度和其他锁定逻辑。阈值是配置，开停时的室温来自采样记录。 |
| `pareto` 成本与未供电量 | 在预算和服务指标同时达标时，哪些方案值得复核？ | 同场景方案组、支配关系、两条限值、可行区域及可行的最低成本方案。 | 复核候选集及场景权重。虚线按成本排序连接已算出的边界点。判断新方案是否可行，需要在同一条件下计算其成本与未供电量。 |

进一步需要判断故障时缺口落在哪里，可用故障情景—节点图加缺口汇总。需要确定下一单位调节资源的买入代价，可将边际成本和可获得容量共轴展示。预测误差应同时按预测步长与条件核对偏差和尾部误差。若问题转向激活是否及时，用观测到的启动事件或正确保留删失的响应时长数据，结合实际时限比较。公开图册有这些用途的合成示例，需用项目自己的算例输出重建。

## 运行内置模板

从技能目录运行。Python 依赖 NumPy 和 Matplotlib，均在技能的 `requirements.txt` 中。`--input` 接收下节的 JSON，`--locale` 控制图中内置文字。按客户模板最终插入宽度传 `--width-mm`，默认 166 mm。

```powershell
python templates/project_engineering_figures.py rebound --input paired-intervals.json --locale zh --width-mm 166 --output figures/rebound.png --plan figures/rebound.plan.json
python templates/project_engineering_figures.py duration --example --locale en --output figures/example-duration.pdf
matlab -batch "addpath('templates'); project_engineering_render('figures/rebound.plan.json','figures/rebound.emf')"
```

`--example` 单独读取 [合成教学输入](../templates/project-engineering-examples.json)。正式图件使用 `--input`，填入从当前工程算例复算的原始量。`--plan` 包含输入哈希、`scope`、实际绘图范围、颜色、字号和计算结果。把它用于对照现场数值或生成 MATLAB 文件，发布前按项目保密要求处理原始量与计划文件。以实际导出文件的 SHA-256 绑定交付图件清单。

## JSON 输入约定

每份输入是一个对象，均有 `scope`。用一句话注明同一对象、比较基准、考察时窗，以及适用时的场景权重。配对由调用方按项目标识核实，图件只在所填范围内作判断。比例、日期和功率单位不从标题猜测。除日历显式缺测项外，数值均须有限。

| 类型 | 需要填写的字段 | 内置复算 |
| --- | --- | --- |
| `duration` | `capacity_kw` 为同一固定上限。`intervals` 每条有唯一 `id`、`hours`（正数）、`baseline_kw`、`candidate_kw`。一条记录代表两方案中同一观察时段。 | 分别按功率排序，在阶梯横坐标累计实际时长。超限电量按超限功率乘时段长度求和。变动的容量可改画逐时余量轨迹，不能把一条常数容量线套在它上面。 |
| `saturation` | `capacity_kw`、`near_kw`，以及按日期升序排列的 `days`。每天有 ISO `date` 和 24 项 `load_kw`。缺测项填 `null`，未纳入比较的日期在范围说明中说明。跨时区或夏令时须先核对小时口径。 | 用容量减负荷。负值是超限，非负且低于 `near_kw` 是低余量。每天四类时长的总和为 24 h。只按每格 1 h 计算。 |
| `energy-bridge` | 从同一电网计量边界独立得到 `baseline_kwh` 和 `candidate_kwh`。`components` 按实际顺序给出唯一的简短 `label` 和有符号 `delta_kwh`。若表量化有舍入误差，可给出有依据的 `reconciliation_tolerance_kwh`。 | 累加各项，核对基准加净变化是否等于调节后购电量。默认公差 10⁻⁶ kWh，只处理浮点误差。无法闭合时先找重复归因或漏项。 |
| `rebound` | 严格递增的 `bin_edges_h`，其中须有启动时刻 `0`、`event_end_h` 和 `recovery_end_h`。`pairs` 每条有唯一 `id`、`reference_kw` 和 `controlled_kw`。功率数组比区间边界少一项，每项为所在区间的平均 kW。 | 在控制和恢复时窗分别对功率差积分。缩短或延长任何一个时窗都会改变电量，所以按同一工程约定积分。负净回补值保留。 |
| `hysteresis` | `on_threshold_c` 高于 `off_threshold_c`。`samples` 每条有递增 `time_h`、`temperature_c`、`power_kw` 和布尔状态 `cooling`，状态来自观测或已验证的仿真。 | 标记相邻样本间的开停变化。左图优先展示一个完整循环，右图保留全部采样；没有完整循环时左图展示当前观测路径。 |
| `pareto` | `currency`、`cost_cap`、`unserved_cap_kwh_per_day`。`candidates` 每条有唯一 `id`、`family`、`daily_cost`、`unserved_kwh_per_day`。各候选使用相同场景、权重及折算时域。 | 同时最小化日成本和未供电量。只有至少一项严格更优且另一项不劣才支配。先筛出满足双限值的方案，再依次按成本、未供电量和方案 ID 选择。无可行方案时在图例直接显示。 |

## 字体与导出验收

模板把中文字形设为微软雅黑加粗。英文、数字和拉丁单位设为 Times New Roman 常规体。混合标签用可见字体段分别渲染。轴名 10 pt，刻度、图例和短标注 8.5 pt，均按最终物理宽度计。标签空间不足时，缩短项目名称或分配更多画幅。当前后端会检查实际渲染边界，Python 还检查可见文字相互遮挡。不要为通过检查缩小图中文字或拉伸插图。

Python 出图可选 600 dpi PNG 或保留矢量线和字体的 PDF。Windows MATLAB 可导出原生 EMF，另有矢量 PDF 和 600 dpi PNG 选项。保留源计划和适用后端，实查中英文轴名、分类刻度、图例、符号及跨面板单位。最终报告按实际宽度插入并检查完整页面，特别核对图注和正文沿用的比较对象、样本范围、积分时窗和约束。可编辑的图形格式以客户要求为准。
