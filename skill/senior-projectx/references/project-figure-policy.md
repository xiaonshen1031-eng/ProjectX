# Project 图件选择与信息量

结果图优先使用能同时解释工程结构和数量关系的绘图模式。取消独立普通柱状图、单一或少量序列的简单折线图、稀疏散点图、二维 Pareto 点图，以及只给几个平均值或排名的默认输出。少量准确数值直接用表。

## 按问题选模式

| 问题 | 优先模式 | 必需输入 |
|---|---|---|
| 资源画像 | GIS分区或节点分布与规模、构成、时间特性的联动视图 | 边界或坐标、区域统计与同步时间序列 |
| 可调潜力 | 容量—持续时长边界、约束可行域、状态转移与恢复过程 | 不同持续时长或状态下实际计算结果 |
| 调度和资源分配 | 时间窗—分配甘特图、功率构成、约束轨迹与剩余容量 | 接入窗口、逐对象逐时段功率、设备边界 |
| 预测对比 | 完整预测轨迹与误差诊断、时段—预测步长误差矩阵、条件误差分布 | 同一测试区间的预测、真实值与条件标签 |
| 工况与增长 | 情景—时间约束图谱、多指标平行坐标、条件响应面 | 实际情景结果及有意义的维度 |
| 方法差异 | 配对效应分布、分层条件对比、消融交互矩阵 | 匹配单位或条件的完整结果 |

这些是选择方向，不是图数或图型配额。不同结论采用互补视图；复杂主图可独立占图，互补的小图才组合，不把报告全部改成热力图。保留已认可且有足够信息的旧图，纯文字修订不重画无关图。

## 曲线、色块与点的用途

真实时序曲线可作为约束诊断或误差诊断的一层，真实可加构成可以用堆叠色块；它们必须与剩余容量、响应窗口、残差或条件分布共同回答问题。不能把平均值排名柱图改名为构成图，也不能给简单折线加阴影、图标或无关子图以规避要求。散点只作为确有逐点信息的条件分布、配对变化或多变量诊断组成，不输出稀疏独立散点图。

图的复杂度来自真实维度和物理关系。没有独立样本就不加统计分布或置信区间，没有观测或求解点就不靠插值补成响应面。图例尽量一行放置；最终宽度下文字、颜色与曲线均需辨识，保持原比例，不拉伸拼页。

## 清单与检查

每张图在清单中写明 `plot_type`、具体 `question`、`source`、`plot_layers`。每层记录 `role`、`encoding`、`evidence_source`、`evidence_definition`；输入文件的哈希与实际图文件一同保存。标题、图例、装饰、平滑本身不算科学信息层。

`scripts/project_plot_policy.py` 检查 Project 的 `artifacts` 清单；通用 `figures` 清单由 `validate_figure_manifest.py` 按相同编码规则检查。检查声明不能代替查看实际图件和正文中的插入效果。

Python模板提供约束轨迹诊断起点，MATLAB模板提供接入窗口与响应分配起点。`project_report.py figures` 的算例依次输出约束—余量诊断、窗口—功率甘特图和情景—时段约束图谱；其他工程研究应使用自己的模型输出。
