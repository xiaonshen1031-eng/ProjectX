# 图件显示修复

适用于乱码、缺边、裁切、图例遮挡或插入后比例异常。先按图题定位实际媒体，再核对用户当前原生源、保存结果、导出物和 Word/PPT 页面。沿作图路径追溯实际输入。缩放、字体和导出路径的修订使用同一真实数据。术语及单位有冲突时回到实际计算和协议。

| 对照 | 检查位置 |
| --- | --- |
| 源内容与计算不一致 | 核实节点、系列、排序、边界和单位 |
| 源正确，独立导出已异常 | 核查字形、字体替换、绘图边界、裁剪和导出器 |
| 导出正确，插入页异常 | 核查媒体关系、格式签名、缩放、图题及用户环境字体 |
| 元素距边过近或遮挡 | 按实际字形调间距或折行，核查轴、标记、箭头和色条端点 |

EMF 的 EMR_EXTTEXTOUTW 按 ETO_GLYPH_INDEX 保存字形编号时，直接读取 Unicode 会产生错误。检查器给出实际框尺寸、已识别字体和字形索引记录数量。具体外观以实际文档为准，其他 EMF 文字形式及 EMF+ 注释也应通过渲染检查。

~~~powershell
python scripts/inspect_emf_text.py figure.emf --json-out work/emf_text.json
~~~

沿同一源重导出。接受位图插入时从正确源直接渲染，实际所需像素宽度为 ceil(插入宽 cm / 2.54 × dpi)。保留需要的矢量及原生公式源。缩小或裁切后检查每边、字形、透明区、标记和单位，核对新旧刊载数据对象。

局部替换先查 [Word图件集成](word-figure-integration.md)，仅更新指定对象和画幅。用 Word 或指定渲染器保存重开并检查当前页。相邻表格、图注、字段和公式的状态由页面和结构证据核实。记录实测环境和显示差异。

本指南及 EMF 诊断改编自 XiaoN 的 NPS Research Paper v3.2.4 Project 图件显示流程。
