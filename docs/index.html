01 / THE PROJECT WORKFLOW

从项目要求开始，
把研究做完整。

先读材料，明确研究对象和承担范围，再把数据、模型、计算与分析接起来。按当前负责的部分推进，也能继续修订已有成果。

01

连贯的技术报告

沿研究对象、模型关系和计算结果展开分析，解释工程含义。按模板处理正文、三线表、居中编号公式和参考文献。

Word · MathType · 图表与分析
02

沿客户模板组织汇报

从整体思路进入模型与算例，组织适合汇报的语言和页面。检查图名、图例、文字容纳和原生对象。

模板PPT · 可编辑对象 · 页面检查
03

可以接着使用的计算材料

把数据处理、模型脚本、参数设置、结果数据和绘图源码整理在一起，便于复算与后续修订。

数据处理 · 模型求解 · 参数与源码
04

把成熟经验用于后续项目

将格式、语言、图件、公式与结果分析中的可复用经验留下来，结合反馈和回归检查持续完善。

经验维护 · 修订反馈 · 回归检查

VISUALIZATION / TWO EXPORT MODES

图型确定后，
再选绘图工具。

MATLAB绘制并导出EMF矢量图，Python绘制并导出PNG图像。两条路径分别提供源码与原图。

01 / VECTOREMF

MATLAB 绘图模式

适合文档排版和放大查看。用原生图元组织曲线、色块、文字、图例和复杂几何关系。

.m 绘图源码 → .emf 矢量图
02 / RASTERPNG

Python 绘图模式

适合插图和在线展示。按明确的画布尺寸与分辨率，输出层次清楚、比例统一的图像。

.py 绘图源码 → .png 图像
