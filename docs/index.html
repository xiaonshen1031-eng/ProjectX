REPORT / .DOCX

连贯的技术报告

沿研究对象、模型关系和计算结果展开分析，解释工程含义。按模板处理正文、三线表、居中编号公式和参考文献。

Word · MathType · 图表与分析
BRIEFING / .PPTX

沿客户模板组织汇报

从整体思路进入模型与算例，组织适合汇报的语言和页面。检查图名、图例、文字容纳和原生对象。

模板PPT · 可编辑对象 · 页面检查
COMPUTE / SOURCE

可以接着使用的计算材料

把数据处理、模型脚本、参数设置、结果数据和绘图源码整理在一起，便于复算与后续修订。

数据处理 · 模型求解 · 参数与源码
REFINE / REUSE

把成熟经验用于后续项目

将格式、语言、图件、公式与结果分析中的可复用经验留下来，结合反馈和回归检查持续完善。

经验维护 · 修订反馈 · 回归检查
